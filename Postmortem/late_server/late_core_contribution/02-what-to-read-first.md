# 02. What To Read First

Recommended reading order:

1. `README.md`
2. `CONTEXT.md`
3. `late-core/src/lib.rs`
4. `late-core/src/db.rs`
5. `late-core/src/model.rs`
6. `late-core/src/models/`
7. `late-core/src/telemetry.rs`

If you are changing a specific persisted domain, read its model file first.
