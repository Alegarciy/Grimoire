# 02. What To Read First

Recommended reading order:

1. `README.md`
2. `CONTEXT.md`
3. `late-ssh/src/main.rs`
4. `late-ssh/src/state.rs`
5. `late-ssh/src/app/state.rs`
6. the feature directory you want to change

Also read local subsystem docs when relevant:

- `late-ssh/src/app/chat/CONTEXT.md`
- `late-ssh/src/app/rooms/CONTEXT.md`
- `late-ssh/src/app/artboard/CONTEXT.md`

If you skip those context files, you'll miss important invariants.
