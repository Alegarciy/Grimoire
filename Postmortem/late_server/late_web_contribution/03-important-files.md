# 03. Important Files

Key files:

- `late-web/src/main.rs` — process bootstrap
- `late-web/src/lib.rs` — app state and router composition
- `late-web/src/config.rs` — env/config loading
- `late-web/src/error.rs` — error responses
- `late-web/src/pages/mod.rs` — route composition root
- `late-web/src/pages/connect/` — landing + pairing page
- `late-web/src/pages/chat/` — browser chat page
- `late-web/src/pages/play/` — browser TUI demo page
- `late-web/src/pages/gallery/` — artboard gallery
- `late-web/src/pages/profiles/` — public work profiles pages
- `late-web/src/pages/shared/now_playing.rs` — shared now-playing fetch logic
- `late-web/src/pages/stream.rs` — stream proxy
