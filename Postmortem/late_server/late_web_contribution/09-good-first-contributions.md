# 09. Good First Contributions

Safer early contribution targets:

- landing page content polish
- template/layout cleanup
- HTMX partial improvements
- profile/gallery presentation improvements
- focused route handler cleanup
- stream-proxy docs or resilience polish

Higher-risk areas:

- websocket URL/protocol behavior
- `/stream` semantics
- changes that require tight SSH/web protocol coordination

Start with a page that is mostly rendering-focused before changing realtime bridge behavior.
