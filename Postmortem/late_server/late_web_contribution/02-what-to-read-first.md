# 02. What To Read First

Recommended reading order:

1. `README.md`
2. `CONTEXT.md`
3. `late-web/CONTEXT.md`
4. `late-web/src/main.rs`
5. `late-web/src/lib.rs`
6. `late-web/src/pages/mod.rs`
7. the page directory you want to change

If the page talks to realtime SSH features, also read the matching `late-ssh` area.
